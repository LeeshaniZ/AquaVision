                          CRITICAL FIXES APPLIED
═══════════════════════════════════════════════════════════════════════════════

1. API ENDPOINT MISMATCH
   ────────────────────────────────────────────────────────────────────────
   Issue:    ESP32 firmware sends data to /api/sensors
             but Flask server only had /sensor-data endpoint
   
   File:     server/app.py
   
   Fixed:    Added dual route decorators:
             @app.route("/sensor-data", methods=["POST"])
             @app.route("/api/sensors", methods=["POST"])
   
   Result:   ESP32 and Python client both work ✅


2. MISSING TARGET_PH RESPONSE
   ────────────────────────────────────────────────────────────────────────
   Issue:    ESP32 expects server to return target_pH for pH control feedback
             but app.py only acknowledged the request
   
   File:     server/app.py, line ~220
   
   Fixed:    Changed response from:
             return jsonify({"status":"received", "alerts": alerts})
             
             To:
             return jsonify({
                 "status":"received", 
                 "alerts": alerts,
                 "target_pH": ALERTS["target_ph"]  # ← Added this line
             })
   
   Result:   ESP32 can now dynamically update target pH from server ✅


3. WINDOWS-SPECIFIC PATH HANDLING
   ────────────────────────────────────────────────────────────────────────
   Issue:    Code used filepath.split('\\') which fails on Linux/Mac
             Broken code: filepath.split('\\')[-1]
   
   File:     server/ai_processor.py (multiple locations)
   
   Fixed:    Replaced with cross-platform functions:
             os.path.basename(filepath)  - Get filename
             os.path.dirname(filepath)   - Get directory
   
   Result:   App works on Windows, Linux, and macOS ✅


4. CAMERA INITIALIZATION WITHOUT ERROR HANDLING
   ────────────────────────────────────────────────────────────────────────
   Issue:    cv2.VideoCapture(0) at module level would crash if camera unavailable
             Original: cap = cv2.VideoCapture(0)
   
   File:     server/ai_processor.py, line ~25
   
   Fixed:    Added try-except block:
             cap = None
             try:
                 cap = cv2.VideoCapture(0)
                 if not cap.isOpened():
                     print("⚠️ WARNING: Camera not available...")
                     cap = None
             except Exception as e:
                 print(f"⚠️ WARNING: Could not initialize camera: {e}")
                 cap = None
             
             Then in generate_frames():
             if cap is None:
                 print("⚠️ Camera not available")
                 return
   
   Result:   App gracefully handles missing camera without crashing ✅
